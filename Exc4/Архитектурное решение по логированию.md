## Анализ текущей архитектуры в контексте логирования

Для понимания состояния сервисов и отладки проблемных ситуаций необходимо внедрить систему логирования.
Необходимо собирать логи для следующих сервисов:
Shop API, CRM API, MES API.

Необходимые логи с уровнем INFO:
- Информация о регистрации нового пользователя
- Изменение статуса заказа
- Информация об успешной оплате
- Информация о постановки заказа в очередь на производство
- Информация об успешном завершении производства
- Информация о входе в любой технический сервис (система мониторинга, трейсинг, управление ресурсами)
- др

## Мотивация

Логирование помогает понять состояние сервисов и приложений. На раннем этапе, когда нагрузка на систему не очень большая и в системе находится не много сервисов, базовой системы логирования будет достаточно. Позже, когда количество сервисов и приложений будет расти, можно внедрять систему трейсинга.

На раннем этапе ресурсы команды ограничены, поэтому внедрение комплексной системы трейсинга будет не совсем оправдано. Сбор и обработка логов позволит вовремя выявить критические сбои, ошибки и проблемы с ресурсами системы.

Предлагается использовать следующие виды логирования:
- Логирование на уровне приложений
- Системное логирование
- Логирование с помощью агентов

## Предлагаемое решение 

Для сбора и обработки логов предлагается использовать специальный набор инструментов - ElasticSearch, Logstash, Kibana. ELK предназначен для извлечения, поиска, анализа и визуализации данных логирования.

Для сбора данных с сервисов предлагается использовать Filebeat.

Для обработки собранных данных, предлагается использовать Logstash — это серверный конвейер обработки данных. 

В качестве базы данных предлагается использовать ElasticSearch. Elasticsearch — это документоориентированная распределённая база данных NoSQL. Она основана поисковой системе Lucene и предоставляет удобный RESTful API. 

Для визуализации данных предлагается использовать Kibana - специальный инструмент, который предоставляет разные интерактивные диаграммы, геопространственные данные, временные рамки и графики для визуализации сложных запросов, которые выполняются с помощью Elasticsearch.
